POS Stock Sync

From Warehouse to POS, Sync without Pause

Features

Stock Sync
The available quantity of a product is synced in real-time across all POS screens. This app will also sync other product attributes, such as price.
Stock Display
The Stock Display option determines how the stock is displayed in the POS screen.

Options

  • In stock/Sold out: Show "in stock" or "sold out"
  • Quantity: Show quantity left
  • Never: Hide the available quantity
Deny order
Specify when a POS order should be rejected. This option can be set for all products or for each product individually.

Options

  • Out of stock: Refuse the order if a product is sold out
  • Quantity: Refuse the order if the product stock gets below a specified quantity. This can be used to allow overselling up to a set limit.
  • Never: Never refuse an order
Warehouse Selection
Choose which warehouses to use in the POS screen. Selecting multiple warehouses allows for switching between them in POS. If no warehouse is selected, the default warehouse is used.
Manual Stock Update
The Manual Stock Update feature allows to manually set products as sold out.
